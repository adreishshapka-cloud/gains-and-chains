# Символы

Файлы здесь нарезаны из общего листа скриптом:

```
python tools/slice_art.py <лист.png>
```

Скрипт сам находит карточки, срезает декоративную рамку, убирает фон заливкой
от краёв и приводит всё к квадрату 128×128. Перерисовал лист — просто прогони
скрипт заново, координаты нигде не зашиты.

Ниже — требования, если класть файлы вручную.
Чего нет — то в игре останется цветной плиткой-плейсхолдером, поэтому
файлы можно подкладывать по одному и сразу смотреть результат.

| `harness.png` | Кожаная портупея |
| `oil.png` | Бутыль масла |
| `shaker.png` | Протеиновый шейкер |
| `rookie.png` | THE ROOKIE |
| `ref.png` | THE REF |
| `champion.png` | THE CHAMPION |
| `duke.png` | DUKE, маскот |
| `wild.png` | ♂ WILD |
| `scatter.png` | DUNGEON DOOR |

| `coin.png` | Значок монеты — не барабанный символ, а интерфейсная иконка. Единственное место на макете, где она встречалась, — цена покупки бонуса; стоит рядом со строкой «Покупка» в правой панели |

## Требования

- **Одинаковый размер** у всех файлов. Квадрат: 96×96, 128×128 — что угодно,
  лишь бы одно на всех.
- **Прозрачный фон.** Символ ложится на тёмное поле барабана, белая подложка
  будет видна как плитка.
- **Без внутренней рамки.** Рамку ячейки и подсветку выигрыша рисует движок,
  вторая рамка на спрайте будет спорить с ней.
- Масштабирование — `nearest`, без сглаживания. Поэтому исходник должен быть
  честным пиксель-артом, а не апскейлом с размытием.

## Цепи

Пять ступеней различаются **цветом металла**, а не надписью:

| Файл | Ступень | Цвет |
|---|---|---|
| `chain-1.png` | ×1 | бронза |
| `chain-2.png` | ×2 | серебро |
| `chain-3.png` | ×5 | золото |
| `chain-4.png` | ×20 | фиолет |
| `chain-5.png` | ×100 | красный |

**Внутри цепи должно быть пусто.** Номинал рисует движок поверх спрайта:
он зависит от текущей ставки, и зашитое в картинку число начнёт врать, как
только игрок сменит ставку.
