# GAINS & CHAINS

**DEEP GAINS. ZERO MERCY.**

Слот-машина для Windows. Подпольный клуб силачей: кожа, масло, цепи и DUKE,
который наблюдает за каждым спином.

Игра полностью офлайн и на виртуальные монеты. Ни сети, ни платежей, ни вывода —
монеты нельзя купить и нельзя обменять, они существуют только внутри игры.

---

## Установка

Нужна Windows 64-бит. Больше ничего — ни браузера, ни Node.

1. Скачать `GainsAndChains-0.1.0-x64.exe`
2. Запустить, выбрать папку, дождаться установки
3. Играть с ярлыка на рабочем столе или из меню «Пуск»

Есть и версия без установки — `GainsAndChains-portable-0.1.0.exe`: один файл,
запускается откуда угодно, хоть с флешки.

### «Windows защитила ваш компьютер»

Такое окно появится при первом запуске. Приложение не подписано сертификатом —
подпись стоит денег и для игры на фантики смысла не имеет.

Нажать **«Подробнее»** → **«Выполнить в любом случае»**.

## Управление

| Клавиша | Действие |
|---|---|
| `Пробел` | Крутить |
| `A` | Автоспин на 25 раундов, повторное нажатие останавливает |
| `T` | Турбо: ускоряет барабаны и показ выигрыша |
| `P` | Правила |
| `F` | Во весь экран |
| `Esc` | Закрыть открытый экран |

Всё то же есть кнопками. Монеты кончились — банка с маслом в нижнем ряду
доливает ещё.

## Что внутри

**♂ STICKY GAINS.** ♂ выпадает на трёх центральных барабанах, прилипает
и растит множитель ×1 → ×2 → ×3. Несколько ♂ на одной линии — множители
перемножаются.

**OIL UP.** Золотые цепи несут номиналы от ×1 до ×100. Кулак DUKE на пятом
барабане забирает все цепи на экране разом. Два кулака — двойной сбор.

**BELT COLLECTION.** Три жетона — и DUKE снимает очки: выплата, вход
в подземелье или горсть липких ♂. Чем дольше нет выигрышей, тем выше шанс
жетона — глухая полоса всё равно к чему-то ведёт.

**DUNGEON RUN.** Три двери на выбор: 10 спинов со стартом ×1, 8 со стартом ×5
или 5 со стартом ×18. Каждый ♂ на поле добавляет +1 к множителю раунда.
Двери сведены к близкому матожиданию — правильного ответа нет, выбор про
темперамент.

**SKIP LEG DAY.** Купить вход в подземелье за 64 ставки. Возврат тот же, что
и при обычной игре: покупка экономит время, а не даёт преимущества.

## Математика

| Параметр | Значение |
|---|---|
| Возврат (RTP) | **95.88%** |
| Поле | 5 × 4, 20 линий |
| Частота выигрыша | 26.3% |
| Вход в бонус | раз в 200 спинов |
| Волатильность | высокая, σ = 15.0 |
| Потолок выигрыша | ×5000 от ставки |

Цифры не на глаз: мат-модель отделена от графики полностью и прогоняется
симулятором на 10 млн раундов. Подробный отчёт, ленты барабанов и обоснование
каждой правки — в [MATH.md](MATH.md).

```bash
npm run sim
```

## Разработка

Нужен Node.js 22+. Для скриптов обработки картинок — Python 3 с Pillow.

```bash
npm install
npm run dev      # игра в браузере, http://127.0.0.1:5173
npm test         # тесты мат-модели
npm run sim      # симулятор: 10 млн раундов
npm run app      # запустить как настольное приложение
npm run dist     # собрать установщик и portable
```

Сборка складывается в `~/gains-build`, а не в папку проекта: путь с кириллицей
ломает распаковщик electron-builder — он падает с EPERM при переименовании
временной папки.

### Как это устроено

```
src/core/     мат-модель: ленты, выплаты, фичи, раунд. Ни строчки про графику
src/game/     сцена, барабаны, показ выигрыша, координаты макета
src/ui/       экраны и кнопки
src/state/    сохранение
tools/        симулятор и обработка картинок
```

Главное правило: **`src/core` не знает о существовании Pixi.** Поэтому мат-модель
гоняется миллионами раундов в консоли, а её отчёты что-то значат. Графика
получает от неё готовый лог событий раунда и разыгрывает его во времени —
второго экземпляра игровой логики не существует.

Второе правило: **интерфейс нарисован на фоне.** Рамки, панели и кнопки —
часть картинки, движок кладёт поверх только то, что меняется, по координатам
из `src/game/layout.ts`. Как пересобрать фон и символы из исходников —
в [src/assets/ui/README.md](src/assets/ui/README.md) и
[src/assets/symbols/README.md](src/assets/symbols/README.md).

Полный план работ и что ещё не сделано — в [PLAN.md](PLAN.md).
Концепт, символы и механики — в [DESIGN.md](DESIGN.md).
